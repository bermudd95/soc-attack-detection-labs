# Response Actions – Credential Abuse Detection

## Initial Validation
- Confirm whether the login activity is expected
- Contact the user if necessary
- Review recent account behavior

---

## Containment Actions
- Reset user credentials
- Revoke active sessions
- Temporarily disable account if risk is high

---

## Escalation Criteria
Escalate to incident response if:
- Lateral movement is observed
- Privileged accounts are involved
- Data access or exfiltration is suspected

---

## Post-Incident Actions
- Document findings and response steps
- Review detection logic effectiveness
- Recommend control improvements
