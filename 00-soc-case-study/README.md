# End-to-End SOC Case Study: Alert Triage and Incident Response

## Overview
This project simulates a SOC analyst monitoring and responding to multiple security alerts during a single shift. The focus is on alert triage, decision-making, escalation criteria, and proper documentation rather than isolated attack simulations.

The goal is to demonstrate how a SOC analyst prioritizes alerts, distinguishes false positives from true incidents, and responds effectively under realistic conditions.

---

## Scenario Summary
During a simulated monitoring period, several alerts were generated across authentication logs and host telemetry. Some alerts indicated potentially malicious behavior, while others were determined to be benign after investigation.

Each alert was reviewed, classified, and handled according to SOC best practices.

---

## Skills Demonstrated
- Alert triage and prioritization
- Log analysis and correlation
- Incident escalation decision-making
- False positive identification
- Incident response documentation
- MITRE ATT&CK mapping
