# Attack Chain Dashboard

## Overview
This dashboard provides visibility into each stage of a multi-stage attack, enabling SOC analyst to quickly identify suspicious activity. 

---

## Panels

### PowerShell Activity
Tracks execution of PowerShell commands, including encoded usage.

---

### Scheduled Task Creation
Identifies persistence mechanisms.

---

### Failed Login Attempts
Highlights authentication anomalies.

---

### Network Activity
Displays outbound connections initiated by PowerShell.

---

### Detection Alers 
Shows triggered rules for immediate investigation. 

---

## Analyst Workflow
1. Identify spike or anomaly
2. Drill into logs
3. Correlate accross panels
4. Investigate alerts

---

## Outcome
Provides a centralized interface for detecting and analyzing attack chains.
