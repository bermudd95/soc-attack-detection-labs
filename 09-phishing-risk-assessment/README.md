# 09 - Enterprise Phishing Simulation & Human Risk Assessment

## 📌 Project Overview
This project models a controlled, 500-user phishing simulation across a multi-department enterprise to identify human-centric vulnerabilities, map defensive reporting timelines, and architect a C-suite ready remediation plan. 

By analyzing multi-stage social engineering vectors (Open → Click → Submit → Report), this assessment provides an actionable blueprint to mitigate identity-harvesting gaps and strengthen corporate defense-in-depth.

## 📂 Project Structure
*   [executive-report.md](./executive-report.md): Formal C-level analysis detailing the strategic business risk, behavioral insights, and technical mitigation roadmap.
*   [dataset-metrics.md](./dataset-metrics.md): Comprehensive data engineering breakdown showing how the 500-user cohort behaved across business units.
*   `Security Awareness Program Assessment & Phishing Simulation Analysis_ (2).xlsx`: The interactive master workbook housing the raw logs, mathematical matrices, and visual charts.
